# Registro de decisiones de arquitectura

Guardar una decisión por archivo, por ejemplo `0001-runtime-and-deployment.md`. No cerrar decisiones que aún dependan de Seguridad, arquitectura corporativa o propietarios de sistemas.

## Plantilla

```markdown
# ADR-NNN: título breve

- Estado: Propuesta | Aprobada | Rechazada | Sustituida
- Fecha: YYYY-MM-DD
- Decisores:
- Jira relacionado:

## Contexto
## Decisión
## Alternativas consideradas
## Consecuencias
## Seguridad y datos
## Sistemas y entornos afectados
## Revisión
```

## Decisiones abiertas

- Runtime, lenguaje, proveedor de modelo y despliegue.
- Identidad, permisos, secretos, registro y retención.
- APIs y scopes para Jira, Confluence y SAP.
- Política para generación y modificación de código ABAP.
- Flujo de aprobación, transporte y promoción entre entornos.
